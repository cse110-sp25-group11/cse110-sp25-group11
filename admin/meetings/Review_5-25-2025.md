# 🏁 Sprint Review – Week of 5/20/2025

## Summary

During this sprint, the team made significant progress across both frontend and backend development efforts, built out pipeline automation, and began laying the groundwork for more rigorous testing practices. While a few blockers emerged around coordination between UI and script development, the team maintained momentum by prioritizing communication, documentation, and debugging.

---

## Key Accomplishments

### Functionality and Features

- Completed **HTML and CSS styling** for core pages like browse and post events.
- Introduced **swipe animations** and **navbar styling** to enhance UI interactivity.
- Built a **carousel** feature and implemented **localStorage** logic for events.
- Progress made on a **liked events page** is pending further clarification.

### Testing and Validation

- Initial **form validation** implemented.
- Research into **unit testing strategies** was conducted.
- Test automation setup is underway for integration into CI/CD.

### DevOps and CI/CD

- A **GitHub Action** was successfully created and merged to run automatic linting and quality checks.
- Build pipeline is functioning but still under refinement—debugging is ongoing for certain checks not triggering as expected.

### Documentation

- Figma mockups were finalized and paired with markdown descriptions.
- A structured **README** and **repository directory tree** are being developed to improve onboarding and team clarity.

---

## Challenges Encountered

- **Overlapping UI and script development** caused confusion about validation logic placement and ownership.
- Some **pipeline checks failed to trigger**, requiring further debugging.
- Clarification needed from leads on **next steps for features** like liked events and positioning.

---

## 🔭 Focus for Next Sprint

- Finalize and test **JS templates** for interactive pages.
- Fully integrate **unit testing** into CI/CD workflows.
- Continue improving **code review consistency** (casing, redundant files, div usage).
- Ensure PRs and documentation are thoroughly reviewed and approved.
